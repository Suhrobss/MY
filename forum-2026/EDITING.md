# Як редагувати сайт MTWTU Youth Forum 2026

## Знайти код на GitHub

Відкрийте [Suhrobss/MY](https://github.com/Suhrobss/MY). Над файлами натисніть перемикач гілок, який зазвичай показує main, виберіть forum-2026-cobalt і відкрийте папку forum-2026. [Прямий перехід до папки](https://github.com/Suhrobss/MY/tree/forum-2026-cobalt/forum-2026).

## Через адмінпанель сайту

Відкрийте [Панель організатора](https://mtwtu-pulse-production.up.railway.app/?page=admin) і увійдіть. У вкладці «Програма» натисніть олівець біля події. Тут можна змінити назву, час, зал, статус, опис і видимість події.

Щоб заповнити картку спікера, відкрийте «Афіша та анонс» у редакторі події. Введіть повне ім’я, посаду, публічну HTTPS-адресу портрета, підпис до фото й за потреби адресу логотипа. Посада, фото й логотип призначені для події з одним спікером. Для кількох імен розділювач — « · ». Якщо людина виступає кілька разів, використовуйте однакове написання імені. Порожній портрет замінюється ініціалами.

У вкладці «Повідомлення» можна публікувати оголошення й, за потреби, надсилати push підписникам. Усі зміни з адмінпанелі зберігаються на Railway і з’являються на живому сайті після збереження.

## Публікація на Railway

Живий сайт запускається в сервісі mtwtu-pulse проєкту mtwtu-youth-forum-2026. Після змін у public запустіть node build.cjs з папки forum-2026. Це оновить вбудовані файли у forum.ts. Запустіть node smoke.cjs для локальної перевірки. Оновіть код чинної Railway Function файлом forum.ts і перевірте статус деплою. Зміни в GitHub самі по собі сайт не публікують.

Пароль адміністратора й параметри сервера задаються у Variables на Railway. Живі дані та push-підписки зберігаються в /data. Зміна початкової програми у forum.ts не замінює програму, уже збережену на цьому томі.
